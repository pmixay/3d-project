# Заявка на чемпионат «3D Профи» - Hefest: новый принтер на базе старого

Направление: **оборудование для 3D-печати**. Команда: **«Печатники»**.

Мы дали вторую жизнь 3D-принтеру Imprinta Hercules H18 2018 года: от оригинала остались рама, механические составляющие и стол, вся электроника, печатная голова и прошивка - новые.
